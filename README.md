# AI Interview Analyzer

An AI-powered interview preparation platform that helps users practice mock interviews, receive AI-generated questions, and analyze their interview performance.

## 🚀 Features

- 🤖 AI-generated interview questions
- 🎤 Mock interview practice
- 📊 AI-powered interview analysis
- 📝 Performance feedback
- 💻 Modern and responsive UI
- 🔐 User authentication
- 🗄️ Supabase integration

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- AI APIs
